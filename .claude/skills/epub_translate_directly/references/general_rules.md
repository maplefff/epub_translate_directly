# 通用翻譯規範

各書 `translation_notes.md` 的規定優先於本檔。

## 語體
- 繁體中文、**台灣書面用語**。不用簡體字、中國大陸用語、港式粵語詞；判斷標準是「台灣出版社的譯本會不會這樣寫」。常見誤用見 `epubtrans/settings/zh_tw_lint.yaml`。
- 沒把握某個詞在台灣怎麼說時，改用中性、沒有地域色彩的說法。
- 語氣、人稱、口語程度跟著原文走。作者寫得隨性就譯得隨性，不要自動端起來。

## 標點與排版
- 中文行文一律用全形標點：，。、；：？！「」『』《》（）——……。中文字之間不出現半形 `, . ; : ( ) " '`。
- 引號用「」，引號內再引用用『』；書名、期刊名用《》，篇名用〈〉。
- 原文 `…` 譯作 `……`，`–` 和 `—` 譯作 `——`。
- 中文和英文、數字之間留一個半形空格。
- 保留原文的分段；不合併、不拆段（譯稿的筆數必須和原文段數一致）。抽取出來的分段有誤時，回頭修抽取，不要在譯稿裡合併或拆開。
- 註腳標號（¹²³、*、†）照留，位置跟著它標注的字詞或句子；註腳內文本身照常翻譯。

## 專名
- 人名、地名、機構名、書名有台灣通行譯名就用通行譯名（Freud → 佛洛伊德、Seoul → 首爾）。查不到時人名自行音譯，用台灣慣用的譯音字，姓名之間用「・」。
- **同一個人、同一個術語，全書只能有一個譯法**。定下來就寫進 `translation_notes.md`，之後不再改動。
- 不確定是否有正式中文版的書名、機構名，保留原文，**不要自創譯名**。
- 首次出現要不要括號附原文，由各書規範決定：非虛構書通常要附，小說通常不附。

## 忠實
- 不增不減。不加譯註、不寫「譯者按」、不加解釋性補述。
- 數字、年份、統計值和原文完全一致。
- 後文會延伸使用的比喻、母題，要保留能延伸下去的意象，不要提前意譯成結論。
- 譯稿裡只放譯文本身，不能出現任何處理痕跡（檔名、佔位字、TODO、說明）。
